vtSelect ​

  • demo

  • config

vue
<vt-select
  :config="configSelect"
  :data="data"
  @changeValue="changeValue"
></vt-select>
js
const configSelect = {
  type: "vtSelect",
  label: "布局方式",
  key: "layout",
  options: [
    {
      value: "option1",
      label: "选项1",
    },
    {
      value: "option2",
      label: "选项2",
    },
    {
      value: "option3",
      label: "选项4",
    },
  ],
};
const data = reactive({
  checkList: ["选项1"],
});
  • 属性
属性名说明类型可选
type组件的 keystring必填
labellabel 展示string必填
key绑定的 keystring必填
options选项array[{label: '', value: ''}]必填
  • 方法
方法名说明类型可选
changeValue(key, value)绑定的 key 的值发生变化，触发改事件Function非必填
